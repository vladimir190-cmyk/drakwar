👉 **[Launch Live Project](https://vladimir190-cmyk.github.io/drakwar/)**

---

## ✨ Key Features

- **Atmospheric Visuals:** Dynamic background layers featuring custom shader/canvas animations (aurora lights, particle atmospheres).
- **Responsive Architecture:** Fully optimized for desktop displays, tablets, and mobile devices.
- **Audio & Media Integration:** Custom audio playback workflows and embedded cinematic content.
- **Modern UI Elements:** Dark-theme Scandinavian and Viking lore-inspired aesthetic.
